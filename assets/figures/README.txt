FIGURES FOR PROJECT PAGES
=========================

Upload an image here with one of these exact names and it appears
on that project's page automatically. Nothing else to edit.

  project-1-a.jpg   project-1-b.jpg   project-1-c.jpg   -> Gel polymer electrolytes
  project-2-a.jpg   project-2-b.jpg   project-2-c.jpg   -> K-S batteries

  project-4-a.jpg                                       -> Solubility data for ML

.png works too (for example project-1-a.png).
Names are case-sensitive: use lowercase exactly as written.

To change the caption under a figure, open the project page in
the "projects" folder and edit the text after <!-- CAPTION: project-1-a -->.
